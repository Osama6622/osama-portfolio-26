# Osama Noshy Maher — Senior Frontend Developer Portfolio

A high-craft, dark-themed developer portfolio built with **Vue 3**, **Vite**, and custom hardware-accelerated directives (`v-reveal` & `v-spotlight`).

## Highlights

- **Obsidian & Emerald-Cyan Dark Theme** (`#090A0F` primary canvas, `#10B981` Vue Emerald, `#38BDF8` Electric Cyan)
- **Interactive Engineering Console** in the Hero section
- **Filterable Career Trajectory** covering NCGR, Link Development, Silky Systems, and Huawei Technologies
- **Interactive Case Study Modals** for flagship projects (Etimad & Debt Management, Monshaat & Tawakkalna, Buyers-Compass, Orange/Etisalat GIS Maps, Philippines Converge, CEM, Enterprise Accounting)
- **Live Reusable UI Component Playground** (`<InputText />`, `<BasicSelect />`, `<RadioButton />`, `<DatePicker />`, `<TableList />`)

## Quick Start

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
